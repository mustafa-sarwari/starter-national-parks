# 🏞️ National Parks Explorer

An interactive web application to explore America's beautiful National Parks. Built with vanilla JavaScript, HTML5, and CSS3, this project showcases modern frontend development practices and responsive design.

> 🌲 Discover the natural wonders of the United States through an intuitive and visually appealing interface.

## 📦 Installation

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn

### Steps

1. **Clone the repository**
   ```bash
   git clone https://github.com/mustafa-sarwari/starter-national-parks.git
   cd starter-national-parks
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm start
   ```

4. **Open in browser**
   - The app will automatically open at `http://localhost:1234`

## 🚀 Usage

### Development
```bash
npm run dev
```
Starts the Parcel development server with hot module replacement.

### Build for Production
```bash
npm run build
```
Creates an optimized production build in the `dist` folder.

### Deploy to GitHub Pages
The project is configured to deploy automatically to GitHub Pages. The built files should be pushed to the `gh-pages` branch or configured in repository settings.

## 🎨 Key Features Explained

### Search Functionality
Users can search for parks by name or keywords in descriptions. The search is case-insensitive and updates results in real-time.

### State Filtering
A dropdown menu allows filtering parks by U.S. state, making it easy to explore parks in specific regions.

### Park Details
Clicking on any park card opens a modal with detailed information including:
- Full park description
- Location and establishment date
- Popular activities
- High-quality images

### Responsive Design
The application adapts to different screen sizes:
- Desktop: Multi-column grid layout
- Tablet: Two-column grid
- Mobile: Single-column layout with optimized touch targets
